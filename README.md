A [make.fun](https://make.fun/bounty/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7) bounty entry: one funny passive-aggressive note a smart fridge leaves for its owner.

## How it works

`main.ts` writes a single line to `/output/entry.txt`:

> My door sensor logged 11 openings after midnight. You ate nothing. I have forwarded the footage to the yogurt, and it is pressing charges.

Run it with Node 22 or later:

```sh
node main.ts
```
